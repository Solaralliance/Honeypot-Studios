# Security policy

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues or discussions. If GitHub private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability** to contact the maintainers privately.

If private vulnerability reporting is unavailable, contact a repository maintainer through a private contact channel already published on their GitHub profile. Do not include exploit details, credentials, or personal data in a public report.

Repository administrators should enable GitHub private vulnerability reporting in the repository's **Settings → Security & analysis** when available.

## Supported versions

Security fixes are made against the current default branch. No other supported release branches are currently specified.
